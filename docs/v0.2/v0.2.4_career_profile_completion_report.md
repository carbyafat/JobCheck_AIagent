# JobCheck V0.2.4 個人履歷資料完成報告

> 功能狀態：已實作、完成使用者人工驗收，並合併至本機 `main`
>
> 完成日期：2026-09-20
>
> Unity 基準：2022.3.62f3 LTS

## 1. 版本目標

V0.2.4 建立第一版「給自己管理的個人履歷母資料」，讓 JobCheck 不再只有公司、職缺與應徵資料。這份資料用於整理自身經歷，未來可供職缺適配分析或履歷文件產生使用；它不是直接投遞給公司的排版履歷。

本版同時加入應用程式外殼與固定側欄，將既有職缺流程和履歷頁分開，為後續首頁與其他功能保留穩定的頁面入口。

## 2. 已完成內容

- 建立 `AppShell`、固定側欄與 `AppPageNavigator`，支援首頁、職缺、履歷三個主要頁面。
- 既有職缺列表與詳細頁歸入 `Page_Jobs`，原有列表、詳細與返回流程保持不變。
- 建立個人履歷 Domain 模型、驗證規則、穩定 ID 與獨立 Repository。
- 履歷資料使用獨立 JSON 儲存，不與職缺搬運格式混用。
- 建立履歷顯示頁與編輯頁，包含自我介紹、連結、技能、語言、工作經歷、專案與學歷。
- 履歷頁全面使用 TextMesh Pro 與 `Yozai-Light SDF`，側欄文字改為繁體中文。
- 顯示區拆成個別標題與內容元件，不以單一長字串承載整頁內容。
- 支援長文字捲動、輸入區遮罩與中文輸入法組字，避免輸入內容顯示 `<u>` 標記。
- 補充履歷模型、Repository 與 AppShell 場景結構測試。

## 3. 驗收結果

- 使用者已確認履歷頁目前可正常使用。
- 頁面切換、履歷顯示、編輯、儲存及重新載入流程已完成實作。
- Unity 專案的 `Assembly-CSharp` 與 UI EditMode 測試組件在收尾期間完成編譯檢查。
- 履歷功能以五個獨立 commit 完成，並以 fast-forward 方式合併至本機 `main`。

## 4. 版本邊界

- 本版不包含履歷跨裝置匯入／匯出。
- 本版不產生給公司投遞的 PDF 或 Word 履歷文件。
- 本版不進行履歷與職缺的適配評分，也不呼叫外部 AI。
- 首頁目前只保留頁面入口，不提供正式摘要內容。
- 職缺資料搬運與履歷資料的檔案格式、入口及風險提示必須維持分離。

## 5. 後續方向

後續版本從 V0.2.5 的履歷資料搬遷開始。完整順序與範圍記錄於儲存庫根目錄 `README.txt` 的「後續方向」。
