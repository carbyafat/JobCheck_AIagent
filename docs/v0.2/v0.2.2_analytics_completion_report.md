# JobCheck V0.2.2 應徵分析完成報告

> 功能狀態：已實作並合併至本機 `main`；本報告為文件收尾
>
> 完成日期：2026-09-18
>
> Unity 基準：2022.3.62f3 LTS

## 1. 版本目標與邊界

V0.2.2 將 V0.2.1 已累積的 JobPosting、Application 和 ApplicationEvent 轉成可閱讀的求職進度統計；Company 主資料仍維持既有關聯，本版不單獨統計公司。分析是唯讀查詢，不寫回 JSON，也不為了讓漏斗完整而虛構事件。資料來源跟隨總攬頁目前選擇的 Demo／個人資料區。

本版完成的原定範圍是應徵漏斗、來源平台成效，以及公司拒絕／我方結束原因等結果統計。文字分析頁足以驗證數字與定義；圖表、自動匯入及 AI 評分不在本版範圍。

## 2. 已完成內容

- `ApplicationAnalyticsReport` 定義唯讀的總覽、漏斗、平台、結果、結束原因與資料品質提醒。
- `ApplicationAnalyticsQuery` 從現有 Repository 載入資料，按本人應徵輪次和有效事件計算報告，不修改來源資料。
- `Panel_Analytics` 顯示可捲動的文字報告，提供資料區名稱、空資料說明和關閉操作；總攬頁已有「分析」入口。
- 查詢測試覆蓋空資料、重投遞、事件補正、遷移快照、資料排除、平台名稱正規化、長期未回覆標記及缺少資料根目錄等情境。
- UI EditMode 測試檢查分析 Prefab 的層級與序列化參考，並防止一次性建置器覆寫現有 Prefab。

## 3. 統計口徑

| 指標 | 目前採用的定義 |
| --- | --- |
| 納入的應徵輪次 | 本人應徵、可找到對應職缺，且不是重複封存、待人工確認或未知階段的 Application。重投遞是另一輪。 |
| 漏斗階段 | 只看有效 ApplicationEvent 曾到達的里程碑；後續階段必須有 `Applied` 事件才納入漏斗。不從目前狀態倒推缺少的歷史。各階段可重疊，不能相加成總數。 |
| 公司有回應 | 已投遞後有已讀、聯絡、安排／完成面試、公司拒絕或 Offer 事件；這個名稱不等於「公司已回信」。單獨的等待回覆事件不算公司有回應。 |
| 漏斗比率 | 各階段輪次 ÷ 有 `Applied` 事件的輪次。分母為零時顯示「—」。 |
| 平台職缺投遞率 | 該平台至少投遞過一次的**不重複職缺** ÷ 該平台收錄職缺。 |
| 平台回應／面試／Offer 率 | 各階段的應徵輪次 ÷ 該平台有 `Applied` 事件的應徵輪次。少於 5 輪時標示僅供參考。 |
| 目前結果 | 每個納入輪次按目前狀態只歸入進行中、取得 Offer、公司拒絕或我方結束其中一類；不等同漏斗歷史。 |
| 我方結束原因 | 只統計目前為我方結束，且有結構化 `CandidateCloseReason` 的輪次。 |
| 長期未回覆 | 有 `NoResponseMarked` 事件的提醒數，不自動把該輪改成我方結束。 |

平台名稱會合併空白並以不區分大小寫的方式分組；未填平台顯示為「未設定平台」。被資料補正事件取代的舊事件不納入漏斗。僅有 migration snapshot 時會顯示提醒，不憑快照推測先前漏斗事件；目前結果仍可按 Application 狀態呈現。

## 4. 資料安全與品質提醒

- 非本人應徵、重複封存、待人工確認、未知階段及找不到對應職缺的 Application 不納入應徵統計，頁面列出相應排除數。
- 個人資料仍留在被 Git 忽略的 `personal_data/`；報告、測試 fixture 和本文件不記錄真實公司、職缺、日期或事件內容。
- 分析查詢不建立缺失的資料目錄；讀取失敗時 UI 顯示錯誤提示，而不是寫入空資料。

## 5. 測試與驗收

- V0.2.2 有 13 個分析查詢 EditMode 測試；後續安全清理另加入 3 個分析 Prefab 安全測試。
- 先前安全清理批次回報完整 EditMode `Run All` **296 passed、0 failed**；這是整套測試的結果，未保留機器可讀結果檔，也不是本次文件修改重新執行的結果。
- 使用者已依人工測試說明確認分析頁開關、捲動、資料區切換及既有入口運作正常。本次文件收尾未再啟動 Unity。
- 尚未對獨立 Build 的資料路徑做正式驗收，目前以 Unity Editor 為使用與驗證基準。

## 6. 已知限制與後續

真實求職資料的公司回應、面試和 Offer 樣本會隨時間累積；目前不能把少量輪次的百分比解讀為平台優劣。後續若發現統計口徑與實際使用直覺不符，應以具體事件與預期數字回報，再調整查詢和測試，不補造不存在的歷程。圖表不是 V0.2.2 的完成條件。

下一個功能版本是 V0.2.3 新版匯入／匯出；V0.2.4 才規劃 AI Fit Score、摘要與面試準備。先前安全清理標記為「待清理」的相容程式與一次性建置路徑，依本次決定暫不移除。
