# V0.2.3 垃圾桶管理驗收

> 驗收日期：2026-09-19
>
> 結果：刪除、垃圾桶還原、單筆永久刪除、清空垃圾桶，以及「先匯出、刪除、再增量匯入補回」均由使用者人工確認 OK。

## 建立同步差異

1. 在個人資料區先執行「資料搬運 → 匯出」，保留完整 `.jobcheck.json`。
2. 選一筆有應徵／事件的職缺刪除，主清單應少一筆；公司與其他職缺不受影響。
3. 打開「垃圾桶」，應看見該職缺、刪除時間與相關應徵數。
4. 回到「資料搬運」，選取步驟 1 的檔案。預覽應把被刪除的職缺及相關應徵列為新增資料；匯入後主清單恢復。
5. 垃圾桶保留原刪除項目，因為搬運同步不會操作本機垃圾桶。測試完成後可永久刪除該回收項目，避免留下重複備份。

## 還原與清除

1. 再刪除一筆職缺，於垃圾桶按「還原所選」。主清單、應徵及事件應恢復，回收項目消失。
2. 若主資料區已存在相同職缺或應徵 ID，還原必須拒絕，不覆蓋兩邊任何檔案。
3. 按「永久刪除所選」第一次只顯示警告；第二次才刪除。切換選項會取消待確認狀態。
4. 「清空垃圾桶」同樣需要按兩次確認。執行後所有可驗證回收項目消失，主資料不變。
5. Demo 資料區只能看到切換提示，不可執行垃圾桶操作。

## 安全邊界

- 垃圾桶只保存在目前裝置，不包含在搬運匯出檔內。
- 永久刪除前會驗證回收項目只能含一筆職缺及其應徵 JSON；若有未知檔案或連結則停止，避免遞迴誤刪。
- 還原只移動原始 JSON，不重建或覆蓋同 ID 檔案；中途失敗會嘗試把已移動檔案放回回收區。
