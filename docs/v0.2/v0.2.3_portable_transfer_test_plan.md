# V0.2.3 個人資料搬運：驗收草案

此功能只搬運 JobCheck 的個人資料（公司、職缺、應徵及內嵌事件），不會從 104 或其他網站抓職缺。匯出檔副檔名為 `.jobcheck.json`，內含 `format_version: "0.2"`、筆數與 SHA-256 校驗碼。校驗碼用於發現檔案損壞，**不是加密或身分驗證**；檔案包含個人求職紀錄，請勿公開上傳。

## 人工驗收

1. 在有測試資料的裝置 A 開啟 JobCheck，切到「個人」資料區，點「資料搬運」→「匯出」。確認畫面顯示完整檔案路徑與公司／職缺／應徵筆數，原本的資料仍可讀取。預設輸出到「文件/JobCheck/Exports」，每次使用新檔名，不覆蓋先前檔案。
2. 在裝置 B 安裝同版本 JobCheck。先切到空白的「個人」資料區，開啟「資料搬運」，將裝置 A 的檔案複製到 B，再把檔案**完整路徑**貼進欄位。點「預覽」，核對匯出時間和四種筆數，之後才點「匯入」。同機匯出會自動把剛產生的完整路徑填入欄位，但現有個人資料區非空，不能再匯入同一區。
3. 匯入成功後關閉面板、按「Load」，逐項檢查公司／職缺、應徵狀態、事件歷程與分析頁筆數。重新啟動程式再確認資料仍在。
4. 再次匯入同一檔，預期顯示「個人資料區已有紀錄」並拒絕；既有資料不得改變。切到 Demo 資料區時，匯出及匯入按鈕應不可用。
5. 複製搬運檔後任意修改 JSON 內容但不更新校驗碼，預覽應拒絕。缺檔、錯誤副檔名、不支援的 `format_version`、重複 ID 或失效的關聯資料也應拒絕。

## 安全邊界

- 匯入只允許不存在的個人資料目錄，或只有三個空白 V0.2 子目錄的個人資料目錄；不提供覆蓋／合併。
- 匯入先寫同層暫存目錄、重新讀取驗證，再更名發布。失敗時不以半套資料替換個人資料區。
- Demo 資料與個人資料分離；使用者應先自行備份原裝置，再處理搬運檔。
- 真實跨裝置驗收需在兩個安裝環境人工執行；自動測試只使用合成資料。
