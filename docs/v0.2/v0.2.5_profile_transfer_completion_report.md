# JobCheck V0.2.5 履歷資料搬遷完成報告

> 功能狀態：已實作並完成使用者人工驗收；待本批合併至本機 `main`
>
> 完成日期：2026-09-20
>
> Unity 基準：2022.3.62f3 LTS

## 1. 版本目標

V0.2.5 讓使用者把 V0.2.4 建立的個人履歷母資料從裝置 A 搬到裝置 B，不必重新輸入。履歷搬運和既有公司、職缺、應徵搬運維持不同檔案格式、服務與 UI 入口。

## 2. 已完成內容

- 定義獨立 `.jobcheck-profile.json` 格式，包含格式版本、匯出時間、履歷 DTO 與 SHA-256 完整性校驗。
- 履歷頁提供「履歷搬遷」，使用檔案選擇器指定匯出位置或挑選匯入檔。
- 匯出要求履歷已實際儲存、不覆蓋既有檔案，也不把搬運檔寫入個人資料目錄。
- 匯入預覽會驗證副檔名、8 MB 上限、JSON、格式版本、校驗碼、Mapper 及 Domain 規則。
- 預覽顯示匯出時間、履歷區塊筆數與即將採取的處理方式。
- 本機沒有履歷時建立；內容完全相同時略過且不寫入。
- 本機內容不同時停用普通匯入，只有使用者明確按「取代本機履歷」才會繼續。
- 取代前把原始 JSON 備份至 `personal_data/profile_backups/`，儲存後再由 Repository 重新載入核對。
- 為 Unity Mono／Windows 可能拒絕 `File.Replace` 的情況加入可回復重新命名流程。

## 4. 安全邊界與限制

- 搬運檔提供完整性校驗但沒有加密，使用者必須自行妥善保管。
- V0.2.5 不做逐欄位合併；不同內容只能取消或整份取代，避免不透明地混合兩份履歷。
- 本版不是即時雙向同步，不傳播刪除狀態，也不處理多裝置同時編輯衝突。
- 搬運檔用於 JobCheck 資料還原，不是給公司閱讀的 PDF／Word 履歷文件。
